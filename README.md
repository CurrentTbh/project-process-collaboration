# 衍川项目流程协作系统

面向中小团队的项目排期与流程协作平台：项目、任务、审批流转、成员权限放在一处，装好就能用。

> 自带运行环境（JRE + MySQL），客户电脑上**不需要另外安装 Java 或数据库**：解压 → 双击 `安装.bat` → 以后双击 `启动.bat`，浏览器自动打开登录页。

---

## 功能

- **项目管理**：立项、成员分配、进度跟踪
- **任务与排期**：任务分派、状态流转
- **流程审批**：提交 → 审批 → 全程留痕
- **成员与权限**：JWT 登录鉴权、RBAC 角色权限、按角色可见的数据范围
- **其他**：附件上传、公告、列表分页查询

## 下载

在本仓库的 **Releases** 页面下载最新版本压缩包（约 200 MB）。

**安装三步：**

1. 解压到**纯英文路径**（例如 `D:\ycpm`），不要放在 `C:\Program Files`
2. 双击 `安装.bat`（只需要一次；跑到第 5 步会问你的数据库密码，也可直接回车用默认密码）
3. 以后双击 `启动.bat`，浏览器会自动打开系统页面

详细步骤、常见问题、局域网多台电脑共用，见压缩包里的 `安装说明.md`。
装好后浏览器自动打开登录页，用默认管理员账号进入：

- 账号：`admin`
- - 密码：`031110`
 
  - 这个密码是登录系统的账号密码；装的时候第 5 步问的是数据库密码，两回事，按回车用默认值即可，不影响登录。

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Java 17、Spring Boot 3.2、MyBatis、MySQL 8 |
| 前端 | Vue 3 + TypeScript、Element Plus、Pinia、Vue Router、Axios |
| 鉴权 | JWT + RBAC 角色权限 |
| 交付 | 前端构建进后端 `static`（单 jar 运行）、便携版 MySQL、内置 JRE、批处理安装脚本 |
